# V1 finish plan (2026-10-12)

Base: `codex/mosaic-vsix-v1-finish-20261011`. Each package is built in its own worktree branched from the base,
committed locally, then merged into the base by the lead. No push, no PR until Julian grants remote publication.

## Fixed IDs (all packages)
- Commands: `datapass.build.newWorkspace`, `datapass.build.newFile`, `datapass.build.importDataset`,
  `datapass.interop.import`, `datapass.interop.export`, `datapass.learning.review`.
- Flashcard deck: `content/learning/flashcards/<deckId>.json` =
  `{format:"datapass.flashcards", version:1, id, title, path, cards:[{id, front, back, lesson?, tags[]}]}`;
  ids like lesson ids, ≤ 80 cards, front ≤ 300 chars, back ≤ 1200, plain text.
- Learning path file: `content/learning/paths/<id>.json` = `{format:"datapass.learning-path", version:1, path, lessons[]}`;
  new paths append one id line to `content/learning/catalog.json`.
- Tests: add files under `scripts/suite/*.test.mjs` (run by `npm test`) and `scripts/ui-suite/*.mjs` (run by
  `test:ui`); never edit the `test` script line.
- `CHANGELOG.md`, `docs/HANDOFF.md`, `docs/HANDOFF_HISTORY.md`: lead only. Packages put their changelog line and
  "Checked / Not checked" notes in their final report.

## P1 · Learning engine + core content
Owns `media/learning/*`, `src/learning/*`, the six existing path files (expand) and new `paths/{git-shell,polars,de-foundations}.json`,
decks `{sql,python,polars,git,de-foundations,warehouse,lakehouse}`, `content/reference/learning-*.md` for those topics,
`scripts/learning_*.mjs`, `scripts/suite/learning_*.test.mjs`, `docs/MOSAIC_LEARNING.md`, one package.json command line.
Optional lesson fields `checks[]` (Practice items, typically quiz), `practice[]`, `missions[]`, `cheatsheet`, `deck`.
Four progress levels kept apart: read (self-report), quizAnswered (concept check submitted, pass/fail), executed
(ran locally, not graded), verified (passed Practice Submit in `.datapass/progress.json`). Flashcards: review session
reusing the Leitner intervals of `src/platform/practiceReview.ts`, state labelled "self-rated". Cheatsheets open as
Markdown preview. Search covers cheatsheets and flashcards. Resume: last lesson + due flashcards + next unverified.
Content: ~16 new lessons, ~220 flashcards, links to existing packs and missions only.
