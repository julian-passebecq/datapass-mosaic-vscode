# A path through the labs

**Datapass: Open Learning** opens six paths, with course notes, teaching diagrams and links to the exercises already installed.

**Read / Watch / Try / Exercise / Explain / Compare** change the composition of the same lesson. Try creates a real SQL or Python file without overwriting edits. Exercise opens the existing Practice solution and uses its grader.

The in-page Learning Path can be hidden. The native Learning Path tree can also be moved to the Secondary Side Bar using VS Code's **Move View** action.

Reading and diagrams require no runtime. Running an example requires the existing local runtime; Python also requires explicit trusted-local-Python opt-in. Spark distributed metrics remain simulated. Reading acknowledgements are self-reports, not grading passes.
